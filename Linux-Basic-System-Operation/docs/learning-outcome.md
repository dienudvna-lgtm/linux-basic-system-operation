# Learning Outcome

Dokumen ini merangkum kemampuan yang dilatih dalam project **Linux Basic System Operation**. Gunakan panduan pada setiap lab untuk berlatih dan mencatat hasil praktik yang benar-benar dilakukan.

## Capaian Pembelajaran

Setelah menyelesaikan seluruh lab, siswa diharapkan mampu:

| No. | Capaian |
| --- | --- |
| 1 | Menampilkan direktori aktif dengan `pwd`, berpindah direktori dengan `cd`, dan melihat isi direktori dengan `ls`. |
| 2 | Membuat file dan direktori, menyalin dengan `cp`, memindahkan atau mengganti nama dengan `mv`, serta menghapus dengan `rm` atau `rmdir` secara hati-hati. |
| 3 | Menggunakan `whoami`, `hostname`, `date`, `uname`, dan `cat` untuk memperoleh informasi dasar. |
| 4 | Membaca permission melalui `ls -l` dan mengubahnya dengan `chmod` menggunakan mode simbolik maupun numerik. |
| 5 | Menjelaskan bagian penting keluaran perintah, membedakan nilai yang berubah antar komputer, dan mencatat hasil pengamatan sendiri. |
| 6 | Menjalankan `scripts/system-info.sh` untuk menampilkan ringkasan informasi sistem. |

## Indikator Keberhasilan

- Perintah dijalankan di terminal Bash pada Debian GNU/Linux 13.
- Siswa dapat menerangkan fungsi perintah dengan kata-kata sendiri.
- Operasi file dilakukan di folder latihan, bukan pada folder sistem.
- Permission yang diminta dapat dibaca kembali menggunakan `ls -l`.
- Catatan dan screenshot berasal dari praktik yang dilakukan sendiri.
